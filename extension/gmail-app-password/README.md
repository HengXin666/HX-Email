# HX-Email Gmail 应用专用密码助手（Chrome 扩展）

一键完成 Gmail 应用专用密码（App Password）接入 HX-Email 的全部前置工作：

1. **两步验证**：检查 / 引导开启（Google 强制要求重新输入密码与手机验证，这一步只能半自动，其余全部自动）
2. **生成 16 位应用专用密码**：自动填名称 → 点「生成」→ 读取弹窗密码 → 复制 `邮箱----密码` 导入行
3. **Gmail IMAP 开关**：在关闭状态下自动勾选「启用 IMAP」并保存

前提：浏览器已登录 Google 账号（脚本检测到未登录时会给出登录入口）。

## 安装（加载已解压的扩展程序）

1. 打开 Chrome，地址栏输入 `chrome://extensions/`
2. 右上角打开「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本目录 `extension/gmail-app-password/`
4. 工具栏出现 🔑 图标，点击即可使用

## 使用

点击插件图标，弹出面板：

| 步骤 | 操作             | 说明                                                                                      |
| ---- | ---------------- | ----------------------------------------------------------------------------------------- |
| ①    | 两步验证         | 打开两步验证页；若未开启，面板会自动点击「开始设置」，随后请你完成 Google 的密码/手机验证 |
| ②    | 生成应用专用密码 | 打开应用专用密码页并自动生成、复制 `邮箱----密码` 导入行                                  |
| ③    | 检查 Gmail IMAP  | 打开 Gmail 设置；若 IMAP 关闭则自动勾选「启用 IMAP」并保存                                |

面板底部可设置：

- **HX-Email 地址**：生成后点「打开 HX-Email」跳转的目标（默认 `http://localhost:8000`）
- **应用名称**：生成的应用专用密码名称（默认 `HX-Email`）

生成成功后：

1. 剪贴板中已是 `邮箱----16位密码` 导入行
2. 打开 HX-Email → 账号 → 添加邮箱 → 服务商选 **Google Gmail** → 接入方式选
   **应用专用密码（IMAP，免 OAuth 配置）** → 直接 Ctrl/Cmd+V 粘贴 → 导入

## 自动模式

插件打开的页面 URL 带 `?hx=auto`（或 `#hx=auto`）时自动执行对应页面的主操作：
应用专用密码页自动生成、两步验证页自动点击「开始设置」、IMAP 设置页自动开启并保存。
手动访问时可自行在地址后追加 `?hx=auto` 触发。

## 文件

| 文件                      | 用途                                                                     |
| ------------------------- | ------------------------------------------------------------------------ |
| `manifest.json`           | MV3 清单：权限（storage/clipboardWrite）、host 权限、content script 声明 |
| `content.js`              | 页面自动化 + 浮动面板（状态检测、生成、复制、IMAP 修复）                 |
| `background.js`           | service worker：转发打开页面、记录最近生成结果、自动打开 HX-Email        |
| `popup.html` / `popup.js` | 工具栏弹窗：三步按钮 + HX-Email 地址/应用名称设置 + 最近结果             |
| `icons/`                  | 扩展图标（16/32/48/128）                                                 |

## 说明与边界

- 脚本只读取页面上的应用专用密码，**不会**读取或保存你的 Google 登录密码；密码只进入剪贴板与本地 `chrome.storage.local`（用于弹窗显示最近一次结果）。
- Google 页面结构可能随时改版，脚本采用多策略选择器（文本 + aria 标签 + 16 位格式正则兜底）；若失效，面板会给出提示并退化为手动复制。
- 两步验证的开启必须由你本人完成 Google 的验证（密码/手机号），脚本无法也不应代劳。
- 生成的密码不会自动过期；如需作废，在 Google「应用专用密码」页删除对应条目即可（建议定期清理旧条目）。

```bash
node --check content.js background.js popup.js
```
